# Code Timer - VS Code Extension

⏱️ 自动追踪编程时间，在状态栏实时显示。

**功能：**
- 自动检测活动/空闲状态
- 状态栏实时显示今日编码时长
- 按项目存储统计数据
- 可自定义空闲超时

**安装：** 从 VS Code Marketplace 安装（即将上架）

**命令：**
- `Code Timer: Show Stats` — 查看今日统计
- `Code Timer: Reset Stats` — 重置今日统计

**设置：**
- `code-timer.idleTimeout` — 空闲超时（秒），默认300
- `code-timer.showInStatusBar` — 是否在状态栏显示

**隐私：** 数据仅存储在本地 `.vscode/code-timer.json`，不上传。
